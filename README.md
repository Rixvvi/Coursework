# Проект "Приложение для анализа банковских операций"

## Описание
Приложение для анализа транзакций, которые находятся в Excel-файле. 
Приложение генерирует JSON-данные для веб-страниц, формирует отчеты, а также предоставляет другие сервисы. 

### Описание модулей
1. Excel-файл с транзакциями хранится в модуле data.

2. В пакете src находятся модули с функциями:

2.1. В модуле **reader** находятся функции для открытия excel и json файлов.

2.2. Данные для анализа и вывода на веб-страницах — это данные с начала месяца, 
на который выпадает входящая дата, по входящую дату.

2.3. Валюты и акции для отображения на веб-страницах заданы в отдельном файле **user_settings.json**.

2.4. Сервисы для простого поиска и поиска по номерам телефонов реализованы в модуле **services**. 
В дальнейшем, возможно, будут добавлены и другие сервисы.

2.5. Функция для формирования отчета трат по категориям за последние три месяца реализована в модуле **reports**. 
В дальнейшем, возможно, будут добавлены и другие отчеты.

2.6. Для функций отчетов также написан декоратор. Он находится в модуле **decorators**. 
Декоратор записывает сформированный отчет в файл.

2.7. В модуле **utils** расположены все вспомогательные функции для чтения файлов.

2.8. В модуле **views** находится функция, которая объединяет функции из модуля **utils** в одну систему.

2.9. В пакете tests находятся тесты на проверку основного функционала прилоежния.

2.10. Финальный модуль проекта, объединяющий модули - **main**.

## Разработка

### Установка
1. Клонируйте репозиторий
```commandline
https://github.com/et2133gii80/bank.git

```
2. Установите зависимости
```commandline
poetry install
```

### Конфигурационные файлы

В проекте есть файлы конфигурации, в которых находятся переменные для записи в них путей к файлам и других параметров.
В файле **.env_template** хранятся API-ключи. Создайте файл .env из копии этого файла и замените значения переменных реальными данными.

### Тестирование 
Проект покрыт юнит-тестами Pytest.

Чтобы запустить тесты с оценкой покрытия выполните команду:
```commandline
poetry run pytest --cov
```
Чтобы сгенерировать отчет о покрытии в HTML-формате, где src — пакет c модулями, которые тестируем. 
Отчет будет сгенерирован в папке htmlcov и храниться в файле с названием index.html.
```commandline
pytest --cov=src --cov-report=html
```
### Логирование
Логирование корректной работы функции и возникающих ошибок реализовано во всех модулях. Лог-файлы создаются в директории logs.
